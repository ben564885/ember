The problem

A pass is not a verdict.

It's a timestamped state that a new fact can invalidate. Every fund passes on companies that later become fundable again — a new round, a hiring spree, a warm path that opens up. Nobody re-checks old passes against new signals. Static CRMs store contacts. Nothing stores why the door might still be open.

The pitch

One query, three conditions

Startups I passed on — where a signal landed after the pass — and I still have a short warm path back in through someone I know.

A multi-hop graph traversal joined against a temporal predicate, in one Cypher statement — the relational equivalent needs a self-join plus a recursive CTE.

What's actually deployed

  • The dashboard shows which tier ran, live, per agent
